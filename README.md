# 우리들의 세계탐험

인도네시아를 포함한 26개국을 여행하며 국기·위치·기후·집·음식·문화·자연 명소·인사말을 배우는 한국어 게임입니다. 외부 패키지 설치 없이 실행합니다.

## 바로 실행

컴퓨터에서는 `index.html`을 열면 됩니다. 태블릿은 GitHub Pages 주소로 접속하세요. 국기·지도와 학습 이미지 78개를 모두 포함해 게임 실행 중 외부 이미지 서버가 필요 없습니다. 설명의 외부 자료 링크는 인터넷이 필요합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. ZIP을 풀고 **index.html이 저장소 최상위에 있도록** 파일과 `assets` 폴더를 업로드합니다. ZIP 파일 자체를 올리는 방식이 아닙니다. `tools`와 디자인 문서는 실행에 필수는 아닙니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch는 main, Folder는 /(root)로 설정하고 Save 합니다.
5. 기존 사이트를 업데이트할 때는 새 파일로 덮어 올리고, 게임 주소를 한 번 연 뒤 열린 게임 탭을 모두 닫았다가 다시 접속하세요. 이전 오프라인 캐시가 새 버전으로 바뀝니다. 학습 기록은 같은 주소의 브라우저에 유지됩니다.
6. 배포가 끝나면 Pages에 표시된 주소를 갤럭시 태블릿 Chrome 또는 Samsung Internet에서 엽니다. ‘홈 화면에 추가’ 메뉴로 바로가기를 만들 수 있습니다.

배포 대상 저장소: https://github.com/wooramii/world-wide

게임 접속 주소: https://wooramii.github.io/world-wide/

## 사용법

- 지도 핀이나 나라 카드를 누르고 ‘이 나라로 출발’을 선택합니다. 작은 나라는 대륙 버튼으로 지도를 확대하거나 나라 카드를 이용하세요.
- 나라별 이야기 카드를 먼저 살펴보고 일곱 미션을 진행합니다. 틀리면 힌트를 보고 재도전하며, 모든 미션을 끝내면 도장을 받습니다.
- ‘소리 켜기’ 후 문제 듣기·이야기 읽어주기를 누릅니다. 기기별 음성 지원이 다릅니다. 일부 현지 언어 음성이 없으면 한글 표기를 함께 읽어 주세요.
- 부모님 화면에서 그림 탐험(2개 보기)과 생각 탐험(4개 보기)을 바꿉니다.
- ‘탐험가 1 / 2’는 독립된 여권입니다. 로그인이나 자동 기기 동기화는 없습니다.
- 첫 선택에 맞히면 복습 간격이 1·3·7·14·30일로 늘어납니다. 재도전한 내용은 당일 다시 복습할 수 있습니다. 날짜는 사용하는 기기의 현지 날짜입니다.
- 브라우저 데이터 삭제나 새 기기로 이동하기 전, 부모님 화면에서 기록 파일을 내려받으세요. 파일 가져오기는 두 탐험가의 현재 기록을 교체하므로 확인 창이 표시됩니다.

## 오프라인

GitHub Pages에서 첫 방문 후 아래에 ‘오프라인 준비 완료’가 표시되면 사진을 포함한 기본 게임을 오프라인으로 사용할 수 있습니다. 음성은 기기의 음성 엔진과 다운로드 여부에 따라 인터넷이 필요할 수 있습니다. 브라우저가 캐시를 비우면 다시 온라인 방문해야 합니다. 파일을 직접 열면 서비스 워커는 작동하지 않지만 로컬 파일로 게임을 실행할 수 있습니다.

## 개발·확인

Node.js 18 이상에서:

```
node tools/build-offline.mjs
node tools/check.mjs
node tools/serve.mjs
```

서버 주소: http://127.0.0.1:4173 . 콘텐츠를 수정하면 `node tools/build-offline.mjs`를 다시 실행하세요. 포함된 파일의 내용으로 캐시 버전을 자동 계산합니다. 서비스 워커가 설치된 기존 화면은 열린 탭을 모두 닫고 다시 열면 업데이트됩니다.

## 콘텐츠 범위

집·음식·언어는 대표 사례이며 문화 전체를 하나로 단정하지 않습니다. 기후 미션은 지역과 시기를 제시하며 실제 일기예보가 아닙니다. 음식·전통 가옥·문화유산은 실제 사진과 지도 78개로 살펴봅니다. 이야기 카드와 미션의 사진을 누르면 전체 모습·설명·작가·라이선스를 크게 볼 수 있습니다. 사진 전체 출처는 PHOTO-CREDITS.html에 있습니다. 기후 준비물 등의 일부 보조 표시는 기기 이모지를 사용합니다. 국기는 기기 이모지가 아닌 포함된 SVG입니다. 세계지도는 자연지리 학습용으로 단순화되어 있고 국가 경계·작은 섬에 한계가 있습니다. 외부 사이트는 부모와 함께 살펴보세요. 출처 및 검증 범위는 SOURCES.md에 있습니다.

## 첨부 사진 수정 버전

싱가포르를 포함한26개국,78개 학습 이미지입니다. 브라질 아마존분지 자료는 지도이며 현재 열대우림 분포도와 구분합니다. 교체된 항목과 사그라다 파밀리아 국가 분류 교정은 REPLACEMENTS.md에 정리했습니다. 기존25개국의 여권·복습 파일을 그대로 가져올 수 있으며,26개국 전체182개 주제 기록도 저장·복원할 수 있습니다.
